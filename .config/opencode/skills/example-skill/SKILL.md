# Example Skill

Use this as a template for a focused, reusable workflow.

1. Replace the frontmatter name with the lowercase, hyphen-separated directory name.
2. Describe concrete trigger terms and when the skill must be used.
3. Add the workflow, constraints, and any validation steps below.

Keep skills narrowly scoped so they are selected only for relevant tasks.
